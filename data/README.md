# Teaching data

`teaching_economics.csv` is a small simulated dataset designed to demonstrate growth rates, price indexes, unemployment, and a binary policy indicator. The values are intentionally plausible-looking but are not observations for any country and must not be cited as official statistics.

For real work, download the current series and metadata from the official sources below. Check definitions, seasonal adjustment, base year, revisions, missingness, and geographic coverage before combining series.

- World Development Indicators: https://databank.worldbank.org/source/world-development-indicators
- ILOSTAT labour data: https://ilostat.ilo.org/data/
- OECD Data Explorer: https://data-explorer.oecd.org/
- Eurostat: https://ec.europa.eu/eurostat/data/database
- U.S. BEA NIPA data: https://apps.bea.gov/iTable/
